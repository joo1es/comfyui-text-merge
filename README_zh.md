# ComfyUI 多文案拼接 (Text Merge)

一个简单的 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 自定义节点：可以输入多个备选文案，通过勾选/取消勾选分别启用或停用，设置合并字符后，将选中的文案连接并输出为单个文本。

## 功能特性

- **动态文案槽位**：使用「+ Add」/「×」按钮随时增加或删除文案槽位（上限为 `MAX_SLOTS`）。
- 每个槽位带独立的「启用/停用」复选框；只拼接已启用且非空的文案。
- 可设置**合并字符**，作为已启用文案之间的分隔符。
- 节点内置**实时预览**，输入时会实时显示拼接结果。
- **三个可选 STRING 输入**（`input_1` ~ `input_3`）：可连接其他节点的文本，其内容也会一并合并到输出中（排列在槽位之后）。
- 输出为单个 **String**（合并后的文本）。

## 安装方法

克隆仓库到 `custom_nodes` 目录：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/joo1es/comfyui-text-merge.git
```

重启 ComfyUI，节点会出现在 `utils/text` 分类下。

## 使用方法

1. 在流程中添加节点 `Text Merge`（分类 `utils/text`）。
2. 在文案槽位中填入需要使用的文案，勾选「Enable Text N」表示包含该槽位，取消勾选表示排除。
3. 使用「+ Add」增加槽位，「×」删除槽位。
4. 设置「Merge Char」（合并字符），例如 `, ` 或 `|`。预览区域会实时显示拼接结果。
5. 可选：将其他文本节点连接到 `input_1` ~ `input_3`，其文本会追加到合并结果之后。
6. 「text」输出即为拼接后的结果。

示例：文案为 `["a", "b", "c"]`，槽位 2 停用，`input_1 = "x"`，合并字符为 `|`，则输出为 `a|c|x`。

## 配置

- 修改 `__init__.py` 中的 `NUM_SLOTS`：节点新建时默认显示的槽位数量。
- 修改 `__init__.py` 中的 `MAX_SLOTS`：节点可拥有的最大槽位数。

修改后会自动同步到前端，重启 ComfyUI 即可生效。
