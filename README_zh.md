# ComfyUI 多文案拼接 (Text Merge)

一个简单的 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 自定义节点：可以输入多个备选文案，通过勾选/取消勾选分别启用或停用，设置合并字符后，将选中的文案连接并输出为单个文本。

## 功能特性

- 最多 4 个文案槽位（数量可配置），每个槽位带独立的「启用/停用」开关
- 可设置**合并字符**，作为已启用文案之间的分隔符
- 只拼接已启用且非空的文案
- 输出为单个 **String**（合并后的文本）

## 安装方法

克隆仓库到 `custom_nodes` 目录：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/joo1es/comfyui-text-merge.git
```

重启 ComfyUI，节点会出现在 `utils/text` 分类下。

## 使用方法

1. 在流程中添加节点 `多文案拼接 TextMerge`（分类 `utils/text`）。
2. 在文案1 ~ 文案4 中填入需要使用的文案。
3. 勾选「启用文案N」表示包含该槽位，取消勾选表示排除。
4. 设置「合并字符」，例如 `, ` 或 `|`。
5. 「合并文本」输出即为拼接后的结果。

示例：文案为 `["a", "b", "c"]`，槽位 2 停用，合并字符为 `|`，则输出为 `a|c`。

## 自定义

- 如需调整槽位数量，修改 `__init__.py` 中的 `NUM_SLOTS` 即可。
- 如需动态增删槽位，或添加前端实时预览，告诉我即可。
